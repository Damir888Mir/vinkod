# Фото для сайта Vinкод

Положите фото в эту папку с такими именами — они автоматически появятся на сайте.
Если файла нет, на сайте показывается аккуратная заглушка «Место для фото».

| Файл | Где на сайте | Рекомендуемый размер |
|---|---|---|
| hero.jpg | Фон главного экрана | 1920×1080 |
| offer-to.jpg | Баннер «Комплекты ТО» | 1200×700 |
| offer-acc.jpg | Баннер «Аксессуары» | 1200×700 |
| about-1.jpg, about-2.jpg, about-3.jpg | Блок «О компании» | 900×900 |
| cat-to.jpg, cat-acc.jpg, cat-body.jpg, cat-light.jpg, cat-susp.jpg, cat-brake.jpg, cat-elec.jpg, cat-charge.jpg, cat-salon.jpg | Категории | 600×600 |
| p-glass.jpg, p-plugs.jpg и т.д. | Карточки товаров (путь задаётся в `data.js`, поле `img`) | 800×600 |

Совет: сжимайте фото через https://squoosh.app до 200–300 КБ.
