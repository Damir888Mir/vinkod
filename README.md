# Vinкод — сайт магазина запчастей для электромобилей

Сайт: https://vinkod.vercel.app

Каждое изменение в ветке `main` автоматически публикуется на Vercel.

## Что где лежит

| Файл | Что внутри |
|---|---|
| `index.html` | Страница сайта: тексты, контакты, адреса, карта 2ГИС |
| `data.js` | Товары, цены, категории и марки авто |
| `styles.css` | Оформление |
| `script.js` | Каталог, поиск, подбор, корзина, заказ в WhatsApp |
| `images/` | Фото (список имён — в `images/README.md`) |

## Как добавить товар

Откройте `data.js` и добавьте строку в `VK_PRODUCTS` по образцу существующих.
`price: null` — показывается «Цена по запросу».

## Интеграция с «МойСклад»

Сайт уже пытается загрузить товары с адреса `/api/products`.
Когда будет добавлен серверный модуль с токеном «МойСклад», товары и остатки
будут подтягиваться автоматически вместо `data.js`.
